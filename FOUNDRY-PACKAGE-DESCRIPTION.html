Symbaroum HUD adds a persistent, Symbaroum-styled player HUD for Foundry VTT v13. It gathers the most-used character information and actions near the Foundry hotbar while preserving the native Symbaroum system rolls and item behavior.

The HUD displays toughness, corruption, defense, armor, attributes, active effects, attacks, experience, load, money, abilities, traits, mystical powers and rituals. Players can switch between accessible actors, use character actions, browse their inventory and drag supported documents to actor-scoped hotbar shortcuts.

A guided, Symbaroum-styled Character Creator covers occupation, Attributes, race, Abilities, Shadow, equipment, personality, friends and group. The same native Item-sheet browser remains available from the finished HUD for purchasing Abilities, mystical powers and Ritualist options with the character's available Experience.

Symbaroum Ind Resources is optional but recommended. When enabled, this HUD delegates storage, rations, quivers, ammunition, maneuvers, money, rest and weapon readiness to the public game.tenebreResources API instead of duplicating those rules.

  • Requires Foundry VTT v13.
  • Requires the Symbaroum system 6.1.6.
  • Recommended: Symbaroum Ind Resources.
  • Languages: English and Brazilian Portuguese.
